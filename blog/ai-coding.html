I don't write code by hand anymore

November 7, 2026

Up until recently I wrote all my code by hand. Read the docs, figure out the logic, type it out, debug with print statements. Now AI writes pretty much all of it.

It started with autocomplete, then chatbots where I'd paste code back and forth. The big change was coding agents that can read the whole codebase, edit files and run commands. At that point I could just hand off a task.

My job now is mostly:

  • Deciding what to build and explaining it clearly
  • Reading every diff before it ships
  • Pushing back when it goes the wrong direction
  • Testing that it actually works

This site is a good example. The old version was a bloated dashboard template with a ton of unused plugins. I rebuilt it with an agent: it made a few mockups, I picked one, and we went back and forth on changes. The new one is one HTML page and a stylesheet.

It's not perfect. AI is confidently wrong sometimes, and it likes to overbuild if you let it. Knowing how to code is still what makes it useful, since you have to be able to tell when the output is bad.

If you haven't tried it yet, start with a side project and review everything it writes.
